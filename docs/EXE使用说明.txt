Wowregister 角色注册助手（Windows 10/11，64 位）

1. 解压后双击 Wowregister.exe，会自动打开本地操作页面。
2. 复制页面上的机器码，交给管理员绑定卡密，再在页面输入卡密激活。
3. 选择模式 1 或模式 2，填写运行轮数，首次建议填 1。
4. 点击“启动脚本”，切回游戏角色列表，按 F6 开始。
5. 按 F10 随时停止，也可以返回页面点“停止”。
6. 用完点击页面右上角“退出工具”，然后关闭页面。

无需安装 Python 或 ChatGPT。浏览器页面只是本地控制界面，实际脚本由 EXE 执行。
关闭浏览器标签不会自动停止；请先按 F10 或点击“退出工具”。

模式 1：7 步返回路线，末步前等待 20 秒。
模式 2：8 步返回路线。
每轮自动生成两个 8–10 位英文名字，识别到失败提示后返回起点。
没有匹配失败提示时会超时停止，实际注册结果需要人工核对。

游戏客户区必须与录制一致：1920×1080、DPI 96（Windows 缩放 100%）。
游戏安装盘符可以不同，程序会在按 F6 后绑定当前前台的 Wow.exe。
运行期间不要移动或缩放游戏窗口，不要手动操作鼠标；切换窗口会停止。

每次启动需要联网验证卡密，运行中也会定期复核；网络或授权失效会停止操作。
卡密仅能用于预先绑定的电脑。本地卡密缓存经 Windows DPAPI 加密保存。
