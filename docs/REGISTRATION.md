# 角色注册操作录制与回放

2026-11-03 v2。Windows 10/11、Python 3.11+；使用项目已有的 Pillow，不需要新增依赖。当前已完成模拟测试，尚未在实际注册页面验收。启用真实录制/回放前必须完成[卡密配置与激活](LICENSING.md)。旧的单名字 v1 文件需要重新录制。

新电脑先双击 `setup_registration.cmd` 安装环境；部署并配置验证接口后，双击 `show_device_id.cmd` 获取机器码（预绑定模式），再用 `activate_license.cmd` 激活。真实录制不提供免卡密开关。

## 先录制一次完整失败流程

1. 打开注册页面，放好窗口，准备到每轮重试的起点。录制与回放时保持窗口大小、显示缩放、页面缩放和布局一致。
2. 双击根目录 `record_registration.cmd`，分别输入两个框的名字。每段独立限制在 6 个汉字或 12 个英文字母以内；混合时按汉字计 2、字母计 1，总计不超过 12。空白、数字、空格和标点会被拒绝，游戏的额外命名规则仍以页面为准。
3. 切回注册页面，松开其他按键，按 **F6** 开始录制。
4. 按正常流程点击阵营、输入框等。点进第一个名字框后按 **F7**；点进第二个名字框后按 **F8**。程序分别清空当前框并填入对应名字，中文也可；每个动作保存名字框编号，回放会按编号取对应名字。请确认页面实际收到两个正确的名字。不要手动打名字，因为普通键盘输入不会被录制。
5. 点击提交，等待失败提示稳定显示。**先不要关闭弹窗**，把鼠标放在固定的失败文字中间，按 **F9** 保存检查点。默认截取鼠标周围 240×80 像素，应覆盖有辨识度的失败文字，避开倒计时、人数、动画，也不要只截通用“确定”按钮。保存后可查看 `data/registration/checkpoint_01.png` 确认区域。
6. 继续点击关闭失败提示，并返回步骤 1 的相同起点。等页面稳定，松开鼠标，按 **F6** 结束并保存。

录制期间每次实际点击都会生效；F7/F8 也会实际输入名字。F9 只截图。F10 或切走窗口会取消本次录制，保留以前保存的文件。热键采用轮询，不拦截按键，目标程序也可能收到 F6/F7/F8/F9/F10；不要在使用这些键触发其他功能的界面录制。

默认文件是 `data/registration/macro.json`，含两个名字、目标程序完整路径、点击坐标、等待时间和检查点图片，仅保存在本地。重新完成录制会覆盖同一路径的旧文件。数据目录已在 Git 忽略列表中，不会随 GitHub 上传；换电脑后应现场录制，不能沿用本机分辨率与坐标。

## 回放和重试

1. 先将注册页面恢复到录制的起点。
2. 双击 `replay_registration.cmd`，第一次输入 **1**，先验证单轮是否完整、名字是否正确、检查点是否能通过。
3. 切回注册页面，按 **F6** 开始。
4. 单轮验证正常后，可再次启动并输入 **30** 等次数，按 F6 开始重试。默认每轮额外间隔 5 秒，保留录制时的各步骤等待。

**F10 随时停止；切走目标窗口、移动或缩放目标窗口也会停止。** 退出或停止时会尝试释放脚本按下的鼠标按钮和按键。回放期间请不要操作鼠标键盘、切标签页或遮挡目标区域。界面变更后需重新录制。

循环回放要求录制过 F9 检查点，且位于最后一次角色名输入之后。回放在检查点连续两次看到相同画面才继续。20 秒内未匹配就停止，并提示人工查看，后面的关弹窗点击和下一轮都不会执行。正常情况下，成功进入不同页面也会使失败检查点不再匹配，从而停止；**这不是成功识别器，不能证明已经注册成功**。选择不合适的区域、相似弹窗、遮挡或画面变化都可能造成误判或停止，实际结果以页面为准。F9 之后只录制关闭失败提示和返回起点的动作。

鼠标使用约 5ms 轮询，支持左右键短点击，保留按下时长及步骤间隔；不支持拖拽、滚轮、组合键、普通键盘录制或极短点击。短时间连点可能漏录，录制时请正常慢速点击。网络等待超过录制时长时，只有 F9 检查点会额外等待，其他动作没有按钮语义识别；应录足页面切换等待时间。

脚本不能改变服务器的阵营限制、名额或失败原因，也没有绕过排队、验证码或服务端限制的功能。

## 命令行

在项目根目录运行，默认只回放一轮：

```powershell
.\.venv\Scripts\python.exe -m wowregister.registration.record --name-first "第一段" --name-second "第二段"
.\.venv\Scripts\python.exe -m wowregister.registration.replay --inspect
.\.venv\Scripts\python.exe -m wowregister.registration.replay
.\.venv\Scripts\python.exe -m wowregister.registration.replay --repeat 30 --interval 5 --timeout 30
```

`--inspect` 只打印动作，不监听热键、不截图、不发送输入，不需要卡密。`--name-first "新名字"` 和 `--name-second "另一段"` 可分别临时覆盖回放的名字；录制时原名如果被显示在其他页面，替换后可能导致画面检查点不匹配。

录制的 `--output` 与回放的 `--macro` 可指定其他 JSON 文件。检查点框大小可用 `--checkpoint-width 300 --checkpoint-height 80` 调整；重录后生效。`--tolerance` 默认 0.02，表示 RGB 任一通道差异大于 24 的像素占比最多 2%；它不是识别概率。不建议为通过检查点而盲目调大容差。

输入使用 Windows SendInput，中文使用 KEYEVENTF_UNICODE；以微软的 [SendInput](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-sendinput) 和 [KEYBDINPUT](https://learn.microsoft.com/en-us/windows/win32/api/winuser/ns-winuser-keybdinput) 文档为依据。目标程序可能拒绝模拟输入；脚本权限低于目标程序时也可能被 Windows 阻止。首次务必现场验证，未通过时不能视为支持当前游戏客户端。
